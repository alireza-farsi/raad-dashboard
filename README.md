# گزارش اعتبارسنجی شرکت رعد

این پروژه پیاده‌سازی کامل گزارش اعتبارسنجی شرکت رعد به‌صورت یک داشبورد React تک‌صفحه‌ای است که **دقیقاً مطابق فایل PDF نمونه** (۸ صفحه محتوایی + یک کاور) طراحی شده است.

## نصب و اجرا

```bash
npm install
npm run dev      # حالت توسعه روی http://localhost:5173
npm run build    # خروجی نهایی در پوشه dist
npm run preview  # پیش‌نمایش خروجی build
```

## فونت

از فونت **Ravi FaNum 02 Light** استفاده می‌شود:
- مسیر فایل: `public/fonts/RaviFaNum-Light.ttf`
- تعریف `@font-face` در ابتدای `src/index.css` با همه وزن‌ها (۳۰۰–۷۰۰) روی همین فایل.

## صفحات (مطابق PDF)

| سایدبار | عنوان صفحه | فایل کامپوننت |
| --- | --- | --- |
| ۱ | درباره شرکت | `src/components/PageAbout.jsx` |
| ۲ | خلاصه گزارش | `src/components/PageSummary.jsx` |
| ۳ | صورت سود و زیان | `src/components/PagePL.jsx` |
| ۴ | ترازنامه | `src/components/PageBalance.jsx` |
| ۵ | اعتباری | `src/components/PageCredit.jsx` |
| ۶ | ارقام مقایسه‌ای (ترازنامه و سود و زیان) | `src/components/PageComparative1.jsx` |
| ۷ | ارقام مقایسه‌ای (ترازنامه و اعتبارات) | `src/components/PageComparative2.jsx` |
| ۸ | عارضه‌یابی اطلاعات مالی | `src/components/PageAnalysis.jsx` |

ساختار هر صفحه دقیقاً مطابق نمونه PDF است:
- **صفحه ۱**: شناسه شرکت (۶ فیلد) + محل فعالیت (۲ فیلد + آدرس + ۵ فیلد تماس) + اعضای هیئت مدیره + سهامداران + محصولات و خدمات ارزیابی دانش‌بنیان.
- **صفحه ۲**: ۷ KPI (درآمد عملیاتی، سود عملیاتی، دارایی جاری، بدهی جاری، مجموع دارایی‌ها، سرمایه ثبتی، تسهیلات فعال بانکی) + دو کارت ظرفیت اعتباری (ضمانت‌نامه پیمانی و سرمایه در گردش) + بلوک Description (شامل رتبه B1، اسکیل ۳۰۰–۹۰۰، سه زیر-امتیاز) + یادداشت مبنای امتیازدهی.
- **صفحه ۳**: جدول صورت سود و زیان ۵ساله (۱۳۹۹–۱۴۰۳) با ۱۲ سطر + جدول ساختار هزینه‌ای با درصد + نمودار روند سودآوری + نمودار روند درآمد با احتساب تورم.
- **صفحه ۴**: دو جدول موازی (سمت چپ: حقوق مالکانه + بدهی‌های غیرجاری + بدهی‌های جاری + جمع کل؛ سمت راست: دارایی‌های غیرجاری + دارایی‌های جاری + جمع کل) با ۴ ستون سال + نمودار روند حساب‌های پرداختنی/دریافتنی/تسهیلات مالی + نمودار سرمایه در گردش به نسبت دارایی‌ها.
- **صفحه ۵**: بنر «سال پایه ارقام اعتباری ۱۴۰۴» + ۴ لیست (بانک‌های ارائه‌دهنده تسهیلات، سایر نهادها، بانک‌های ناشر ضمانت‌نامه، صندوق‌های ناشر ضمانت‌نامه) + نمودار مقایسه روند درآمدی با تسهیلات دریافتی + جدول ۷ سطری شاخص/توضیحات.
- **صفحه ۶**: ۴ بخش (هر کدام جدول کوچک + نمودار): نسبت پوشش بهره، بدهی‌ها به حقوق صاحبان سهام، سودآوری، دارایی‌ها به سرمایه ثبتی.
- **صفحه ۷**: ۴ بخش در چیدمان ۲×۲ (هر کدام جدول کوچک + نمودار): نسبت آنی، نسبت مالکانه، نسبت وام فعال به ح.ص.س، نسبت جاری.
- **صفحه ۸**: جدول ۲ ستونه شاخص/وضعیت با ۴ دسته (دارایی‌ها و بدهی‌ها، حقوق مالکانه، درآمد سود و زیان، رفتار اعتباری) — پرچس زرد برای وضعیت نقدینگی.

## منبع داده

داده‌ها از فایل نمونه API (JSON با کلید `invoices`) استخراج شده‌اند. برای بازسازی `raadData.json` از روی فایل تازه:

```bash
python3 /home/z/my-project/scripts/extract_raad_data.py
```

این اسکریپت از بخش‌های زیر استفاده می‌کند:
- `company_info`, `knowledge_base`, `board_of_directors`, `share_holders`, `products` — برای صفحه ۱
- `credit_rank_and_capacity`, `credit_real` — برای صفحات ۲ و ۵
- `income_statement`, `fin_ratio` — برای صفحات ۳ و ۶
- `balance_sheet` — برای صفحات ۴ و ۶
- `facilities_report` — برای استخراج لیست بانک‌ها و تسهیلات چندساله (صفحه ۵)
- `pivot_fin_diagnose_view` — برای جدول عارضه‌یابی (صفحه ۸)

## ساختار فایل‌ها

- `src/App.jsx` — چیدمان اصلی، مسیریابی ۸ صفحه، مدیریت state فیلتر سال.
- `src/components/Sidebar.jsx` — منوی کناری با ۸ آیتم.
- `src/components/Page*.jsx` — هر صفحه یک کامپوننت مجزا.
- `src/utils/format.js` — توابع قالب‌بندی اعداد فارسی، مبالغ، درصد.
- `src/utils/echartsTheme.js` — تنظیمات مشترک ECharts با فونت Ravi FaNum و اعداد فارسی.
- `src/utils/exportUtils.js` — خروجی Excel و PDF.
- `src/data/raadData.json` — داده استخراج‌شده.
- `public/fonts/RaviFaNum-Light.ttf` — فایل فونت.

## قابلیت‌ها

- فیلتر سال مالی ۱۳۹۶ تا ۱۴۰۴ که تمام صفحات را به‌روزرسانی می‌کند.
- خروجی Excel از داده‌های مالی چندساله.
- خروجی PDF از صفحه فعلی (با html2canvas + jsPDF).
- همه نمودارها با ECharts، با اعداد و فونت فارسی و راست‌چین.
